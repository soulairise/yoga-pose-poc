## 1. 도메인 설명 — 어떤 업무·현장인가

**요가·명상 지도 현장**입니다.

- 소울라이즈 동아리와 요가명상학과에서 그룹 수업을 운영합니다.
- 한 클래스에 10~20명이 같은 아사나를 동시에 수행합니다.
- 지도자는 앞에서 시퀀스를 이끌면서 동시에 각 수련자의 자세를 봅니다.
- 회원이 집에서 혼자 수련하는 경우도 많고, 이때는 봐 줄 사람이 없습니다.

이번 PoC의 대상 동작은 **웃카타아사나(Utkatasana, 의자 자세)** 계열의 **반복 수행**입니다.
무릎을 굽혔다 펴는 구조라 관절 각도로 정량화하기 좋고, 초보자 클래스에서 가장 자주 쓰입니다.

## 2. 현재의 문제 — 지금은 어떻게 하고 있으며 무엇이 번거로운가

### 지금 하는 방식

| 하는 일 | 방법 |
|---|---|
| 반복 횟수 세기 | 지도자가 구령을 붙이며 눈으로 셈 |
| 충분히 앉았는지 확인 | 지도자가 눈으로 봄 |
| 개인별 기록 | 남지 않음 |

### 번거로운 지점

**① 동시 처리에서 무너집니다.**
한 명을 볼 때는 문제가 없습니다. 10~20명이 동시에 하면 세는 일에 주의가 나뉘고, 그 사이 자세를 놓친 반복이 생깁니다.

**② 지속 시간에서 무너집니다.**
수업 후반으로 갈수록 판정이 느슨해집니다. 숙련자의 정확도 자체는 높지만, **같은 판정을 반복하면 후반이 앞과 달라집니다.**

**③ 혼자 수련할 때는 아예 없습니다.**
회원이 집에서 할 때 반복 깊이를 확인해 줄 사람이 없습니다.

**④ 기록이 남지 않습니다.**
"오늘 12회 중 3회가 얕았다"를 다음 수업에서 참고할 방법이 없습니다.

### ⚠️ 병목은 정확도가 아닙니다

> 이 업무 유형(검사와 판독)에서 **도입 근거를 "AI가 사람보다 정확하다"로 잡으면 대개 도입할 값이 없다는 결론이 나옵니다.**
> 숙련 지도자 한 명의 판정 정확도를 도구가 넘기는 어렵습니다.

**병목은 일관성과 지속 시간, 그리고 동시 처리입니다.** 이 PoC의 도입 근거도 거기에 둡니다.

## 3. 개선 가설 — AI를 어떤 단계에 어떻게 넣는가

### 가설

> **측면에서 촬영한 영상에 자세 추정 모델을 적용하면,
> 반복 횟수와 "충분히 앉지 않은 회차"를 지도자 판정과 같은 수준으로 자동 산출할 수 있다.
> 그러면 지도자는 세는 일에서 벗어나 자세 교정에만 주의를 쓸 수 있다.**

### 넣는 단계

```
[기존]  수련  →  지도자가 세면서 동시에 자세를 봄  →  기록 없음

[개선]  수련  →  측면 촬영  →  자세 추정 → 무릎 각도 → 반복 판정
                                         ↓
                       지도자는 자세 교정에만 집중 / 회차별 기록이 남음
```

### ★ 설계 원칙 — 지시가 아니라 표시

이 업무는 **사람의 몸에 영향을 주는 일**입니다. 잘못된 교정 지시는 부상으로 이어집니다.
그래서 이 PoC의 AI는 **최종 판정을 내리지 않고, 확인이 필요한 회차를 좁혀 사람에게 넘깁니다.**

| ❌ 하지 않는 것 | ✅ 하는 것 |
|---|---|
| "무릎을 더 굽히세요" | **"3회차·7회차가 목표 각도에 못 미쳤습니다"** |
| 자동 합격 / 불합격 | 신뢰도가 낮은 구간은 **`계산 제외`로 표시해 사람에게 넘김** |

### ★ 판정 항목을 왜 둘로 좁혔는가

요가에서 **"정렬이 맞는가"는 유파마다 답이 다릅니다.** 아쉬탕가·아헹가·빈야사가 같은 자세를 다르게 판정합니다.
판정 기준이 사람마다 다른 일은 **학습시킬 정답도 채점할 방법도 없습니다.**

그래서 판정 항목을 **"옳고 그름"이 아니라 "측정 가능한 값"** 으로 바꾸고, 둘만 남겼습니다.

| 이번 PoC에서 판정하는 것 | 이번 PoC에서 판정하지 않는 것 |
|---|---|
| ① 반복 횟수 | 무릎이 안으로 모이는가 |
| ② 목표 무릎 각도에 못 미친 회차 | 등이 굽었는가 · 어깨 정렬 · 호흡 |

> 항목을 늘리면 항목마다 기준을 따로 세워야 하고, **기준을 세울 자료가 없는 항목이 생깁니다.**
> PoC는 판정 하나가 되는지 확인하는 단계입니다.

## 4. 대상 사용자 — 누가 가장 도움을 받는가

| 사용자 | 지금 겪는 것 | 개선 후 |
|---|---|---|
| **① 그룹 수업 지도자** (1순위) | 세는 일에 주의가 나뉘어 자세를 놓침 | 세는 일을 넘기고 **교정에만 집중** |
| **② 혼자 수련하는 회원** | 깊이를 확인해 줄 사람이 없음 | 촬영 후 **얕았던 회차를 스스로 확인** |
| **③ 지도자 양성 과정 수강생** | 판정 감각을 기를 기준이 없음 | 자기 판정과 수치를 **나란히 놓고 대조** |

## 5. 성공 기준 — 무엇이 얼마나 좋아지면 성공인가

> **⚠️ 아래 기준은 PoC를 만들기 전에 적었습니다.**

### 정량 기준 (둘 다 만족해야 성공)

| # | 기준 | 측정 방법 |
|---|---|---|
| **S1** | **반복 횟수가 지도자가 센 것과 20회 중 18회 이상 일치** | `data/ground_truth.csv`의 `reps_true`와 대조 |
| **S2** | **목표 각도에 못 미친 회차 표시가 지도자 판정과 F1 0.7 이상** | `shallow_reps`와 대조 |

### 처리 시간 기준 (참고 지표)

| # | 기준 |
|---|---|
| **S3** | 영상 1건 처리가 **영상 길이보다 짧다** (실시간보다 빠름) |

### ★ 숫자의 근거 — 현행 수준

> 기준의 근거는 **지금 사람이 하는 수준**입니다.
> 사람이 20회 중 1회 틀리는 업무라면, 3회 틀리는 도구는 도입할 값이 없습니다.

**측정 방법**: 사람이 영상을 보며 반복을 세고, **그 결과와 걸린 시간**을 기록합니다.
이것이 `data/ground_truth.csv` 의 `reps_true` 와 `manual_seconds` 이고, **기존 방식의 숫자**입니다.

| 측정 | 결과 |
|---|---|
| 사람이 센 반복 횟수 | `data/ground_truth.csv` |
| 사람이 세는 데 걸린 시간 | 같은 파일 `manual_seconds` |
| 도구와의 대조 | `docs/03_검증결과.md` |

> ⚠️ **이번 PoC에서 재지 못한 것**: 지도자 **두 사람의 판정 일치도**입니다.
> **사람끼리의 일치도가 도구 기준의 천장**이므로, 실제 도입을 결정하려면 이 숫자가 있어야 합니다.
> 사람이 85%밖에 일치하지 않는 판정을 도구에 95%를 요구하면, 그 기준은 애초에 만족될 수 없습니다.
> → `docs/04_한계와_다음단계.md` 5절에 다음 단계로 적어 두었습니다.

### 기준을 못 넘어도 성과입니다

PoC의 산출물은 작동하는 물건이 아니라 **판단**입니다.
기준을 넘으면 구축 대상이고, 못 넘으면 **그 이유**가 결과물입니다.

## 6. 적용하지 않기로 한 것 (범위 밖)

| 항목 | 왜 뺐는가 |
|---|---|
| 정렬의 옳고 그름 판정 | **판정 기준이 유파마다 다름** → 정답을 만들 수 없음 |
| 자동 교정 지시 | **몸에 영향을 주는 일** → 최종 판정을 도구가 내면 안 됨 |
| 좌우 무릎 벌어짐 | **정면 촬영이 필요** → 이번 영상(측면)으로는 판정 불가 |
| 실시간 피드백 | PoC 범위 밖. 먼저 사후 분석이 되는지 확인 |

## 7. 촬영 조건 — 판정 항목이 정하는 것

자세 추정 모델은 관절 좌표를 **화면 가로·세로 + 카메라 쪽 깊이** 세 값으로 냅니다.
**깊이는 한 장의 사진에서 추정한 값**이라 보이는 좌표와 성질이 다릅니다.

| 판정할 것 | 필요한 촬영 방향 | 이유 |
|---|---|---|
| **무릎 굽힘 깊이** ← 이번 항목 | **측면** | 앞뒤 관계가 화면 가로축(**보이는 좌표**)에 놓임 |
| 무릎이 발끝을 넘었는가 | 측면 | 정면에서는 **추정한 깊이값**에 의존하게 됨 |
| 좌우 무릎 벌어짐 | 정면 | 측면에서는 앞다리가 뒷다리를 가려 **신뢰도가 크게 떨어짐** |

> **하나의 영상으로 이 셋을 다 판정할 수 없습니다. 모델을 더 좋은 것으로 바꿔도 해결되지 않습니다.**
> **판정 항목을 정하면 촬영 절차가 함께 정해집니다.**

**이번 촬영 절차**: 측면 · 전신이 화면에 들어오게 · 카메라 고정 · 밝은 조명

## 8. 자료 처리 방침

- 회원의 몸이 찍힌 영상입니다. **외부 서비스로 전송하지 않습니다.**
- 모든 처리는 **노트북에서 로컬로** 수행합니다.
- 영상 원본은 저장소에 커밋하지 않습니다 (`.gitignore`). 검증에 필요한 것은 **좌표·각도 CSV와 판정 결과**뿐입니다.
